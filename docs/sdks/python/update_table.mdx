## Description

The UPDATE statement updates rows in a table from a data source connected to MindsDB.

## Syntax

Here is the syntax:

```sql
UPDATE datasource_name.table_name
SET column1 = value1, column2 = value2
WHERE condition;
```

Check out the [SQL syntax](/sql/api/update) to better understand how the UPDATE statement works.
